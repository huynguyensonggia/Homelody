Nhập thực đơn từ file

Điền tab Do uong trong file Excel mẫu, rồi chọn file để xem trước.

Chỉ thêm món mới. Món có cùng tên và cùng nhóm được bỏ qua. Nhận XLSX hoặc CSV UTF-8, tối đa 5MB và 500 món. Có thể điền trên Google Sheets rồi tải xuống dạng Excel.

Ảnh: nhập link trong cột Link ảnh, hoặc tải ảnh từ máy sau bằng nút Sửa món. Ảnh chèn trong ô Excel không được nhập.
